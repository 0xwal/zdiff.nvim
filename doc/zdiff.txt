1. INTRODUCTION                                           *zdiff-introduction*

zdiff.nvim is a minimal, fast git diff viewer for Neovim. It provides a
collapsible tree view of changed files with inline diff display and
treesitter syntax highlighting.

Inspired by Zed's multi-buffer diff view - a clean, collapsible interface
for reviewing changes across multiple files without leaving your editor.

Features:
- View uncommitted changes or changes compared to any git ref
- Expand/collapse files to see inline diffs
- Treesitter syntax highlighting in diff views
- Sticky file headers while scrolling expanded diffs
- Jump directly to source files at the correct line
- Auto-refresh when returning to zdiff buffer
- Tab completion for branch/tag names

==============================================================================
2. REQUIREMENTS                                           *zdiff-requirements*

- Neovim >= 0.9.0
- git (must be in PATH)
- (Optional) nvim-treesitter for syntax highlighting

Run `:checkhealth zdiff` to verify your setup.

==============================================================================
3. COMMANDS                                                   *zdiff-commands*

                                                                      *:Zdiff*
:Zdiff[!] [ref] [dir]
    Open zdiff to view changes.

    Without arguments, shows uncommitted changes (diff against HEAD),
    limited to the current directory (see |zdiff-config-scope|).
    With a git ref argument, shows changes between that ref and HEAD.
    With a directory argument, limits the listing to that directory.

    Arguments are order independent: an argument that names an existing
    directory sets the scope, any other argument is treated as a git ref.
    With [!], the whole repository is listed regardless of
    |zdiff-config-scope|.

    Examples: >
        :Zdiff              " Uncommitted changes below the cwd
        :Zdiff!             " Uncommitted changes in the whole repo
        :Zdiff main         " Changes vs main branch
        :Zdiff develop      " Changes vs develop branch
        :Zdiff v1.0.0       " Changes vs tag v1.0.0
        :Zdiff HEAD~5       " Changes vs 5 commits ago
        :Zdiff origin/feat  " Changes vs remote branch
        :Zdiff lua          " Uncommitted changes under lua/
        :Zdiff main lua     " Changes vs main under lua/
        :Zdiff lua main     " Same, order does not matter
<
    Tab completion is available for branch names, tag names and
    directories.

4. KEYMAPS                                                     *zdiff-keymaps*

These keymaps are available in the zdiff buffer:

    <CR>        Go to the file/line under cursor. Opens the file and
                positions cursor at the corresponding line.

    <Tab>       Toggle expand/collapse for the file under cursor.
                When expanded, shows the inline diff with syntax
                highlighting.

    m           Toggle between uncommitted mode and branch mode.
                In branch mode, diffs against |zdiff-config-default_branch|.

    R           Refresh the diff view. Preserves expanded state and
                cursor position.

    q           Close zdiff and delete the buffer.

    ?           Show help popup with all available keymaps.

All keymaps are configurable via |zdiff-configuration|.

5. CONFIGURATION                                         *zdiff-configuration*

Call the setup function with an optional configuration table: >lua

    require("zdiff").setup({
      -- Whether files are expanded by default
      default_expanded = false,

      -- Default branch for toggle_mode (m key)
      default_branch = "main",

      -- Header line template, used when no VCS specific one is set
      header = "diffs(<branch>): <path>",

      -- Optional per VCS templates, each wins over `header`
      git_header = nil,
      jj_header = nil,

      -- Which template wins in a colocated jj+git repository
      header_priority = "git",

      -- Default listing scope: "cwd" or "root"
      scope = "cwd",

      -- Paths shown in the list and winbar: "root" or "scope"
      path_display = "root",

      -- Paths written by yank_ref (gy): "root" or "scope"
      yank_path = "root",

      -- Keymap bindings
      keymaps = {
        goto_file = "<CR>",
        toggle = "<Tab>",
        close = "q",
        refresh = "R",
        toggle_mode = "m",
        help = "?",
      },

      -- Icons for UI elements
      icons = {
        collapsed = "",
        expanded = "",
        added = "+",
        deleted = "-",
        modified = "~",
      },
    })
<

                                               *zdiff-config-default_expanded*
default_expanded ~
    Type: `boolean`
    Default: `false`

    When `true`, all files are expanded by default when opening zdiff.

                                                 *zdiff-config-default_branch*
default_branch ~
    Type: `string`
    Default: `"main"`

    The branch to diff against when using toggle_mode (m key).
    This allows quick switching between uncommitted changes and
    branch comparison without typing the branch name.

                                                         *zdiff-config-header*
header ~
    Type: `string`
    Default: `"diffs(<branch>): <path>"`

    Template for the header line at the top of the zdiff buffer, used in
    both git and jj repositories. See |zdiff-config-git_header| and
    |zdiff-config-jj_header| for per VCS templates.

    Placeholders: >

        <branch>  Current git branch. In a jj repository, the bookmarks
                  pointing at `@`, comma separated, or the short change
                  id when no bookmark points at `@`.
        <path>    Active scope directory, or the repository directory
                  name when the whole repository is listed.
        <scope>   Active scope directory, empty for the whole repository.
        <root>    Repository directory name.
        <ref>     Base ref being diffed against, empty in uncommitted
                  mode.
        <mode>    "Uncommitted changes" or "Changes vs <ref>".
        <desc>    First line of the jj description of `@`. Only valid in
                  |zdiff-config-jj_header|.
<
    A placeholder may carry literal text inside its angle brackets,
    before and after the name. Those affixes take the placeholder's
    highlight group, and they disappear together with the value when the
    value is empty: >lua

        jj_header = 'diffs(<branch>): <path> <"desc">',
<
    With a description, that renders: >

        diffs(main): w/y/z "fix the header lookup"
<
    and the quotes use |ZDiffHeaderDesc|, not |ZDiffHeaderText|. On a
    change with no description, the value, the quotes and the space
    leading up to them are all dropped: >

        diffs(main): w/y/z
<
    Affixes may be any characters except letters, digits and angle
    brackets, so `<(branch)>`, `<[scope]>` and `< | desc>` all work.
    Writing the quotes outside the brackets keeps them literal, and they
    remain when the description is empty: `<path> "<desc>"` renders
    `w/y/z ""`.

    An unknown placeholder is an error: zdiff reports it once and falls
    back to `header`, or to the default template when `header` itself is
    invalid. `setup()` validates all three templates immediately.

    ` (loading...)` is appended while the file list refreshes.

    The default template does not distinguish uncommitted mode from a
    ref comparison; include `<mode>` if you diff against refs often: >lua

        header = "diffs(<branch>): <path> - <mode>",
        header = "zdiff: <mode> in <path>",
<
    The `<branch>` and `<desc>` lookup runs asynchronously, once per
    refresh, and the header renders without them until it returns. A
    template using neither skips the lookup entirely. If `jj` or `git`
    cannot report a value, the placeholder expands to an empty string.

                                                     *zdiff-config-git_header*
git_header ~
    Type: `string|nil`
    Default: `nil`

    Header template used in git repositories. Overrides |zdiff-config-header|.
    Accepts every placeholder except `<desc>`.

                                                      *zdiff-config-jj_header*
jj_header ~
    Type: `string|nil`
    Default: `nil`

    Header template used in jj repositories. Overrides |zdiff-config-header|.
    Accepts every placeholder, including `<desc>`: >lua

        require("zdiff").setup({
          header = "diffs(<branch>): <path>",
          jj_header = "diffs(<branch>): <path> | <desc>",
          git_header = "diffs(<branch>): <path>",
        })
<
                                                *zdiff-config-header_priority*
header_priority ~
    Type: `"git"|"jj"`
    Default: `"git"`

    A colocated repository has both a `.jj` and a `.git` directory, so it
    is both kinds at once. This setting decides which one wins there: it
    selects the template (|zdiff-config-git_header| or
    |zdiff-config-jj_header|) and the command that resolves `<branch>`.

    With the default `"git"`, a colocated repository shows the git branch
    and cannot use `<desc>`. Set `"jj"` to get jj bookmarks and
    descriptions there.

    A repository with only `.jj` is always treated as jj, and one with
    only `.git` is always treated as git, whatever this is set to.

                                                          *zdiff-config-scope*
scope ~
    Type: `"cwd"|"root"`
    Default: `"cwd"`

    Which part of the repository is listed when no directory argument is
    given. With `"cwd"`, only changes below the current working directory
    are listed, so opening Neovim in a subdirectory of a large repository
    hides changes in sibling directories. With `"root"`, the whole
    repository is listed.

    `:Zdiff!` lists the whole repository for one invocation.

                                                   *zdiff-config-path_display*
path_display ~
    Type: `"root"|"scope"`
    Default: `"root"`

    How file paths are labelled in the file list and the winbar. With
    `"root"`, paths stay relative to the repository root
    (`w/y/z/a.lua`). With `"scope"`, the active scope prefix is stripped
    (`a.lua`), which is shorter but no longer matches the paths git
    prints.

    Only the labels change; |zdiff-keymaps| `<CR>` always opens the
    correct file.

                                                     *zdiff-config-yank_path*
yank_path ~
    Type: `"root"|"scope"`
    Default: `"root"`

    Whether the reference yanked by `gy` uses the repository-root path or
    the path relative to the active scope. Independent of
    |zdiff-config-path_display|.

                                                        *zdiff-config-keymaps*
keymaps ~
    Type: `table`

    Table of keymap bindings. Set a key to `false` to disable it.

                                                          *zdiff-config-icons*
icons ~
    Type: `table`

    Icons used in the UI for collapsed/expanded states and file status.

6. HIGHLIGHTS                                               *zdiff-highlights*

The header line is highlighted per component, so each placeholder from
|zdiff-config-header| can be styled on its own: >

    ZDiffHeader           Base group for the whole header line.
                          Links to |hl-Comment| by default.
    ZDiffHeaderText       Literal text between placeholders.
    ZDiffHeaderSeparator  The dashed line below the header.
    ZDiffHeaderBranch     <branch>
    ZDiffHeaderPath       <path>
    ZDiffHeaderScope      <scope>
    ZDiffHeaderRoot       <root>
    ZDiffHeaderRef        <ref>
    ZDiffHeaderMode       <mode>
    ZDiffHeaderDesc       <desc>
    ZDiffHeaderLoading    The " (loading...)" suffix.
<
File header lines are highlighted per component too: >

     ~ lua/zdiff/git.lua  +104 -0
    ^ ^        ^            ^    ^
    | |        |            |    ZDiffRemoveCount
    | |        |            ZDiffAddCount
    | |        ZDiffFileName
    | ZDiffIconAdd / ZDiffIconDelete / ZDiffIconChange
    ZDiffIcon
<
    ZDiffIcon         Expand/collapse indicator. Links to |hl-Directory|.
    ZDiffIconAdd      Status icon of an added or untracked file.
                      Links to |hl-DiffAdd|.
    ZDiffIconDelete   Status icon of a deleted file. Links to
                      |hl-DiffDelete|.
    ZDiffIconChange   Status icon of any other file. Links to
                      |hl-DiffChange|.
    ZDiffFileName     File path. Links to |hl-Directory|.
    ZDiffAddCount     The `+N` count. Links to |hl-DiffAdd|.
    ZDiffRemoveCount  The `-N` count. Links to |hl-DiffDelete|.

The same groups are used in the |winbar| of the zdiff window.

Every header component links to `ZDiffHeader` unless you define it, so
styling `ZDiffHeader` alone restyles the whole header: >lua

    vim.api.nvim_set_hl(0, "ZDiffHeader", { link = "Title" })
    vim.api.nvim_set_hl(0, "ZDiffHeaderBranch", { fg = "#a6e3a1", bold = true })
    vim.api.nvim_set_hl(0, "ZDiffHeaderDesc", { link = "Comment", italic = true })
<
All defaults are set with `default = true`, so a colorscheme wins over
them, and they are reapplied on |ColorScheme|.

==============================================================================
7. FUNCTIONS                                                 *zdiff-functions*

                                                               *zdiff.setup()*
zdiff.setup({opts})
    Initialize zdiff with the given options. See |zdiff-configuration|.
    This is optional - zdiff works without calling setup().

                                                                *zdiff.open()*
zdiff.open({ref}, {dir})
    Open zdiff with the specified git ref.
    Parameters:
        {ref}   Git ref to diff against (e.g., "main", "v1.0.0").
                If `nil` or omitted, shows uncommitted changes.
        {dir}   Directory to limit the listing to. If `nil` or omitted,
                |zdiff-config-scope| decides. `false` forces the whole
                repository.

    Examples: >lua
        require("zdiff").open()           -- Uncommitted changes
        require("zdiff").open("main")     -- Changes vs main
        require("zdiff").open("HEAD~3")   -- Changes vs 3 commits ago
        require("zdiff").open(nil, "lua") -- Uncommitted changes in lua/
        require("zdiff").open(nil, false) -- Whole repository
<
